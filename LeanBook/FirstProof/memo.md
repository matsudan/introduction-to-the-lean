## 足し算の定義

17行目 n はスコープが異なるので区別しやすいように k と置いて

```
  | .succ k => MyNat.succ (MyNat.add m k)
```
左側: 
n が MyNat.succ x という形ならこのパターンに当てはまる。例えば 3 なら succ (succ (succ zero)) なのでこのパターンで、k は 2 (succ (succ zero))が入る。

右側:
(m + k) + 1 を表す。求めたいのは m + n = m + (k + 1)。これを (m + k) + 1 と分けると、m + k は第2引数が1小さい足し算なので add の再帰呼び出しで計算でき、+ 1 は succ を付ければよい。これを繰り返すと第2引数はいずれ zero になり、16行目で止まる。
